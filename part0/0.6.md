# 0.6: New note in the single-page application diagram

```mermaid
sequenceDiagram
    actor user as User
    participant browser as Browser
    participant server as Server

    user->>browser: Types a note and clicks Save
    Note right of browser: The submit handler prevents the default form submission
    Note right of browser: JavaScript creates the note with its content and date
    Note right of browser: Adds the note to the local list, clears the input, and redraws the page

    browser->>server: POST /exampleapp/new_note_spa (JSON note)
    activate server
    Note over browser,server: Content-Type: application/json
    Note over server: Adds the note to the server's in-memory list
    server-->>browser: 201 Created
    deactivate server

    Note right of browser: The browser stays on the page; no redirect or reload occurs
```
