# 0.5: Single-page application diagram

```mermaid
sequenceDiagram
    actor user as User
    participant browser as Browser
    participant server as Server

    user->>browser: Opens /exampleapp/spa
    browser->>server: GET /exampleapp/spa
    activate server
    server-->>browser: HTML document
    deactivate server

    browser->>server: GET /exampleapp/main.css
    activate server
    server-->>browser: CSS file
    deactivate server

    browser->>server: GET /exampleapp/spa.js
    activate server
    server-->>browser: JavaScript file
    deactivate server

    Note right of browser: The browser executes spa.js

    browser->>server: GET /exampleapp/data.json
    activate server
    server-->>browser: List of notes in JSON format
    deactivate server

    Note right of browser: JavaScript renders the notes in the page using the DOM
```
