# 0.4: New note diagram

```mermaid
sequenceDiagram
    actor user as User
    participant browser as Browser
    participant server as Server

    user->>browser: Types a note and clicks Save
    Note right of browser: The form submits the note field using POST

    browser->>server: POST /exampleapp/new_note (note content)
    activate server
    Note over server: Creates a note with its date and adds it to an in-memory array
    server-->>browser: 302 Found (Location: /exampleapp/notes)
    deactivate server

    browser->>server: GET /exampleapp/notes
    activate server
    server-->>browser: HTML document
    deactivate server

    browser->>server: GET /exampleapp/main.css
    activate server
    server-->>browser: CSS file
    deactivate server

    browser->>server: GET /exampleapp/main.js
    activate server
    server-->>browser: JavaScript file
    deactivate server

    Note right of browser: The browser runs main.js and requests the updated notes

    browser->>server: GET /exampleapp/data.json
    activate server
    server-->>browser: List of notes in JSON format
    deactivate server

    Note right of browser: JavaScript renders the list again, including the new note
```
